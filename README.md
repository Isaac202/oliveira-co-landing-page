# Oliveira & Co Tecnologia — Landing Page

Landing page institucional da Oliveira & Co Tecnologia: produção de landing pages sob demanda para gestores de tráfego, agências e infoprodutores, com entrega em até 3 dias.

Site estático de página única (`index.html`), sem dependências de build — HTML, CSS e JS puros.

## Antes de publicar

Atualize o número de WhatsApp real no final do `index.html`:

```js
var WHATSAPP_NUMBER = '5511900000000'; // TODO: substituir pelo número real da Oliveira & Co
```

## Rodando localmente

Basta abrir o `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```
